# VELTRIX ARENA — QR Payment & Webhook Integration

## 1. Overview & NPCI Architecture

VELTRIX ARENA features an extensible Payment Service Provider (PSP) adapter supporting standard NPCI UPI Dynamic QR protocols.

### QR URI Specification
Dynamic QR codes generated by VELTRIX ARENA adhere to the National Payments Corporation of India (NPCI) URI specifications:
```
upi://pay?pa=veltrixarena@sandbox&pn=Veltrix+Arena+Gaming&tr={INTENT_REF}&am={AMOUNT}&cu=INR&tn=Veltrix+Wallet+Deposit
```

Parameters:
- `pa`: Payee Virtual Payment Address (VPA)
- `pn`: Payee registered legal merchant entity
- `tr`: Unique transaction intent reference (e.g. `VLTX-QR-A1B2C3D4E5`)
- `am`: Decimal monetary amount formatted to 2 decimals
- `cu`: Currency code (`INR`)
- `tn`: Transaction note / memo

---

## 2. Dynamic QR Lifecycle

1. **Initiation**: Player selects or enters deposit amount (min ₹50, max ₹500,000).
2. **Intent Creation**: Backend generates a `PaymentIntent` with status `PENDING` and a 15-minute countdown expiry.
3. **Dynamic Presentation**: Next.js UI renders the QR graphic and dynamic deep link buttons for mobile apps (Google Pay, PhonePe, Paytm).
4. **Verification**: Gateway receives payment and posts an HMAC-SHA256 signed webhook callback.
5. **Atomic Settlement**: Backend checks idempotency key `PAYMENT_INTENT_{ref}`. If valid, marks intent `COMPLETED` and debits gateway clearing, crediting the player's `MAIN` balance.
6. **Replay Protection**: Duplicate webhook deliveries are detected via unique database constraints and safely return HTTP 200 without double-crediting.
